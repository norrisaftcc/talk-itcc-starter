# PC Build Checklist

Purpose: a parts check and a first-boot (POST) check for one desktop PC build.

Build name: [lab bench 1]   Date: [date]

## Parts

- [ ] CPU and motherboard use the same socket
- [ ] RAM type matches the motherboard (DDR4 or DDR5)
- [ ] Power supply has enough watts and the right cables
- [ ] Storage drive (SSD) and its cable or M.2 screw
- [ ] CPU cooler and thermal paste
- [ ] Case fans connected to fan headers
- [ ] Anti-static strap on before you touch parts

## First boot (POST)

- [ ] 24-pin and CPU power cables seated
- [ ] Monitor cable in the graphics card, not the motherboard (if the PC has a card)
- [ ] PC shows the BIOS/UEFI screen. If not, write the beep code or LED here: [code]
- [ ] BIOS/UEFI sees all RAM and the SSD
- [ ] CPU temperature at idle in BIOS: [°C]
