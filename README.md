# ITCC Starter Repository

This repository is a place to keep your IT notes and small tools. GitHub saves every version of every file.

It has one starter file for each club track. Pick one. Edit it. Make it yours.

| File | Track |
|---|---|
| `printer-fix-steps.md` | Help desk |
| `switch-vlan-notes.md` | Network |
| `ioc-notes.md` | Cybersecurity |
| `pc-build-checklist.md` | Hardware |

## How it works: edit, commit, History, diff

1. **Edit.** Open a file. Select the pencil icon. Change one line.
2. **Commit.** Select **Commit changes**. Write a short message, for example "Add step for driver check." A commit is a saved version with your message.
3. **History.** Open the file. Select **History**. You see every commit for that file, newest first.
4. **Diff.** Select a commit. GitHub shows what changed. Lines that start with `+` were added. Lines that start with `-` were removed.

## Add your own tool

1. Select **Add file > Create new file** (or **Upload files**).
2. Give the file a clear name, for example `wifi-troubleshooting.md` or `ping-sweep.py`.
3. Write the first line as a one-line purpose: what the file is for.
4. Commit it with a message that says what you added.
5. Add a row for it to the table above.

## Do not commit

- Passwords, PINs, or recovery codes
- API keys, tokens, or private keys
- Real user data: names, emails, phone numbers, ticket contents
- Employer or campus configuration files, unless you have permission
- Real hostnames or IP addresses from a work or campus network

If you commit one by mistake, deleting the file is not enough. The old version stays in History. Change the password or key first. Then ask for help.
